# 🗺️ Application de Gestion des Infractions Géolocalisées

📍 **Stage** : Agence Urbaine de Béni Mellal  
🗓️ **Période** : Juillet 2024 – Août 2024  
🛠️ **Technologies** : Laravel, Bootstrap, jQuery, AJAX, Vue.js, JavaScript, HTML, CSS, Leaflet

---

## 🚀 Description du Projet

Cette application web a été développée dans le cadre d’un stage à l’**Agence Urbaine de Béni Mellal**. Elle permet la **gestion efficace des infractions urbanistiques** avec une interface moderne et interactive.

L’objectif principal est de faciliter le travail des **contrôleurs sur le terrain** et d’offrir aux **administrateurs** un **tableau de bord** intuitif pour l’analyse et la **visualisation géographique des infractions**.

---

## 🧩 Fonctionnalités principales

### 👮 Côté Contrôleur
- Saisie rapide des informations d’infractions depuis le terrain
- Géolocalisation des infractions sur carte (Leaflet)
- Interface simplifiée et responsive

### 🖥️ Côté Administrateur
- Tableau de bord d’analyse des données
- Filtres par zones, dates et types d’infractions
- Visualisation des infractions sur une carte interactive

---

## 🧰 Stack Technique

- **Backend** : Laravel (PHP)
- **Frontend** : Bootstrap, HTML, CSS, JavaScript, Vue.js, jQuery, AJAX
- **Cartographie** : Leaflet.js pour la visualisation des points sur carte

---

## 📌 Objectif et Impact

> L'application améliore considérablement la collecte, l'organisation et l'analyse des infractions. Elle offre un **gain de temps** pour les agents sur terrain et une **vue d’ensemble précise** pour les décideurs via le tableau de bord.
